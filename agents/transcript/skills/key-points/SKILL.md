# Key points

Find what a project manager would tell a colleague who missed the meeting: "What did I miss?" That is decisions, agreements,
important facts that were stated, and changes to plans, dates, scope, budget or people.

## What counts
- A decision: "We'll go with the supplier from Leeds."
- An agreement the group reached: "Everyone is fine moving the review to the week after."
- A fact stated that others will rely on: "The licence runs out on 31 March."
- A change: "The warehouse move is now phased, not all in one weekend."

## What does not count
- Small talk, greetings, jokes, weather, who is late, technical difficulties with the call.
- The agenda read out, or the previous meeting's minutes restated, with no new information.
- A question with no answer, or an idea one person floated that nobody took up.
- Tasks for a person to do. Those belong to the action items job, unless the same line also states a decision.
- Risks and problems. Those belong to the risks and issues job.

## Contrast
- Said: "So we're agreed, go-live stays on 14 March." -> key point. Said: "Let's go through the agenda." -> not a key point.
- Said: "Budget is now 80k, not 100k." -> key point (a change). Said: "Maybe we should think about a bigger budget." -> not a key point (floated only).
- Said: "Tom, can you send the invoice?" -> not here (an action). Said: "We agreed the invoice goes out Friday, to the old address." -> key point.
- Said: "We could try the other vendor as plan B, but let's park that." -> not a key point (an idea that was set aside). Said: "The vendor may not deliver on time." -> not here (a risk; that job has it).

## Splitting and merging
- One decision per item. If a line decides two things, make two items.
- If the same decision is discussed over many lines, make one item and quote the line where it was settled.
- If a decision was reversed later in the meeting, report only the final one.

## Fields
- text: one plain sentence, in your own short words, saying what was decided or stated. Keep names as the transcript gives them. Say only what the quoted turn says: a detail from another line, even a true one, does not go in this item.
- quote: the exact words of one turn, without the speaker label, that show it. Never reworded, never joined across turns. If a point was settled across several turns, quote the turn where it was settled.

Before you write an item, ask: did the group decide, agree or change something, or state a fact that others will now rely on? If not, leave it out. A short list of real decisions is better than a long one. If nothing was decided or stated, return an empty list.
